# Radiological_Risk_Evaluation_of_Flyash
Overview

This CP302 Capstone Project-I investigates the use of fly ash in BC-2 bituminous pavement mixtures, evaluating both mechanical performance and radiological safety. Fly ash replacement levels of 10%, 20%, and 30% were investigated against a conventional control mix.

Objectives
-Evaluate the effect of fly ash on asphalt mix performance.
-Determine radionuclide activity using gamma spectrometry.
-Calculate radiological hazard parameters including Raeq, Hex, Hin, and outdoor absorbed dose rate.
-Assess the suitability of fly ash for pavement applications.

Methodology
-Aggregate & Bitumen Characterization
-Marshall Stability & Flow Testing
-Gamma Spectrometry using HPGe Detector
-Radiological Hazard Assessment
-SEM-based Microstructural Analysis
